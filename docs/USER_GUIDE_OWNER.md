# 🏡 Guide Utilisateur — Propriétaire (Bailleur)

## 1. Publication d'Annonce & Reversements
1. **Inscription & Approbation KYC** : Créez votre compte propriétaire sur `/inscription/proprietaire/`. Votre compte est validé par le SuperAdmin sous 24h.
2. **Ajout d'un Logement** : Complétez les détails du bien (Titre, surface, équipements, prix par nuit). Vous pouvez utiliser l'IA intégrée pour rédiger une description professionnelle.
3. **Réception des Reversements** : À la confirmation du paiement du séjour par le client, votre reversement net (déduction faite des 15% de commission plateforme) est planifié sur votre tableau de bord `/dashboard/owner/`.
